# Model Manifest

Every model we pull, with its source, creator, license, and intended use. This is the record that keeps us honest if we ever sell prints.

**Licensing reality:** MakerWorld's default = **personal printing only**. Everything below is fine to print for ourselves / Clarabel. Do **not** sell prints of these without buying a per-model commercial license (or modeling our own in `../model-forge`).

**How to download:** these need a logged-in MakerWorld account. Fastest path — install **Bambu Studio**, sign in, and hit **"Open in Bambu Studio"** on each page (it pulls the model pre-configured, ready to slice). Then save the raw file into the matching `raws/` subfolder if you want a local copy.
